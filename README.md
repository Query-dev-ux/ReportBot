# ReportBot

Telegram-бот для ежедневных отчетов баеров. aiogram 3, PostgreSQL, Docker Compose.

## Запуск

```bash
cp .env.example .env   # заполнить BOT_TOKEN и ADMIN_KEY
docker compose up -d --build
```

Таблицы создаются автоматически при старте. Деплой на VPS — в [DEPLOY.md](DEPLOY.md).

## Настройка группы

1. Добавьте бота в группу-форум (супергруппу с темами) **администратором** —
   так он сможет писать в темы и видеть их переименования.
2. Для каждого баера должна быть своя тема. Имя баера в боте = название его темы.

ID группы можно брать как `3944138604`, так и в формате Bot API `-1003944138604`.
ID темы — число из ссылки на сообщение в теме: `t.me/c/3944138604/4/...` → `4`.

## Авторизация

| Роль   | Команда                          |
|--------|----------------------------------|
| Баер   | `/unlock 3944138604/4` (группа/тема) |
| ТимЛид | `/unlock 3944138604` (группа)    |
| Админ  | `/unlock <ADMIN_KEY>`            |

ТимЛид должен состоять в указанной группе, баеру это не нужно. При авторизации баера бот
пишет подтверждение в его тему и берет оттуда ее название.

## Возможности

**Баер**
- «Создать новый отчет» — шаблон отчета группы. Дату писать не нужно: отчет
  записывается на день отправки (по МСК) и публикуется в тему баера с заголовком «Отчет за ДД.ММ.ГГ».
- «Посмотреть последний отчет» — с кнопкой «Изменить». Обновленный отчет
  публикуется в тему ответом на исходный: «Отчет за …» + исходный текст + «Обновлен:» + новый текст.

**Админ** — «Посмотреть отчеты баеров» → группа → баер → 3 последних отчета.

Шаблон отчета задается отдельно для каждой группы:
- `/template` — справка и список групп с ID
- `/template 3944138604` — показать текущий шаблон и прислать новый следующим сообщением
- `/template 3944138604 текст шаблона` — сразу задать шаблон (можно в несколько строк)
- `/cancel` — отменить ввод шаблона

Пока шаблон группы не задан, баеры получают шаблон по умолчанию.

**ТимЛид** — «Посмотреть отчеты баеров» → баер своей группы → 3 последних отчета.

**Рассылка вопросов** (админ и ТимЛид) — «Разослать вопрос» → отметить баеров
(админ видит всех, ТимЛид — только свою группу) → «Готово» → текст вопроса.
Баер получает вопрос в личку и отвечает кнопкой «Ответить» или реплаем.
Ответ публикуется в тему баера:

```
Вопрос: Какие задачи на сегодня?
Ответ от KOD: Сделать креатив
```

**Напоминания** — каждый день в `REMINDER_TIME` (по умолчанию 14:00 МСК) баерам
без отчета за сегодня приходит напоминание, а в тему General каждой группы — список
не сдавших отчет.
