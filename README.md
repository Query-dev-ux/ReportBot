# ReportBot

Telegram-бот для ежедневных отчетов баеров. aiogram 3, PostgreSQL, Docker Compose.

## Запуск

```bash
cp .env.example .env   # заполнить BOT_TOKEN и ADMIN_KEY
docker compose up -d --build
```

Таблицы создаются автоматически при старте.

## Настройка группы

1. Добавьте бота в группу-форум (супергруппу с темами) **администратором** —
   так он сможет писать в темы и видеть их переименования.
2. Для каждого баера должна быть своя тема. Имя баера в боте = название его темы.

ID группы можно брать как `3944138604`, так и в формате Bot API `-1003944138604`.
ID темы — число из ссылки на сообщение в теме: `t.me/c/3944138604/4/...` → `4`.

## Авторизация

| Роль   | Команда                          |
|--------|----------------------------------|
| Баер   | `/unlock 3944138604/4` (группа/тема) |
| ТимЛид | `/unlock 3944138604` (группа)    |
| Админ  | `/unlock <ADMIN_KEY>`            |

Баер и ТимЛид должны состоять в указанной группе. При авторизации баера бот
пишет подтверждение в его тему и берет оттуда ее название.

## Возможности

**Баер**
- «Создать новый отчет» — шаблон отчета; дата берется из текста («Отчёт за 14.03.26»).
  Отчет публикуется в тему баера.
- «Посмотреть последний отчет» — с кнопкой «Изменить». Обновленный отчет
  публикуется в тему ответом на исходный: «Отчет за …» + исходный текст + «Обновлен:» + новый текст.

**Админ** — «Посмотреть отчеты баеров» → группа → баер → 3 последних отчета.

**ТимЛид** — «Посмотреть отчеты баеров» → баер своей группы → 3 последних отчета.

**Напоминания** — каждый день в `REMINDER_TIME` (по умолчанию 14:00 МСК) баерам
без отчета за вчера приходит напоминание, а в тему General каждой группы — список
не сдавших отчет.
